# Flipkart Clone — Static E‑Commerce UI

A responsive, static front-end built with vanilla HTML, CSS and JavaScript. It recreates common e‑commerce flows (browse, cart, address, checkout) for learning and UI demos.

## Quick start

1. Open a terminal in the project folder.
2. Start a local static server (recommended):

```bash
python -m http.server 8000
# or
npx http-server -p 8000
```

3. Open http://localhost:8000 in your browser.

## What this project contains

- Static pages: index.html, product.html, cart.html, checkout.html, login.html, address.html, payment.html
- Category pages: html/*.html
- Styles: css/*.css
- Scripts: js/*.js (cart, auth, product, checkout, etc.)
- Images: assets/images/

## Notes

- This is a static project that uses `localStorage` for persistence. There is no backend or real payment integration.
- Use developer tools to inspect app state and debug flows.
